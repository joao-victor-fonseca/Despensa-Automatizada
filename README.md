## 🛒 Sobre o app

Em casa, ninguém confere a validade de cada pacote. Produtos esquecidos vencem atrás de outros na prateleira, e o resultado aparece no lixo e no bolso.

A **Despensa Automatizada** resolve isso: você cadastra o produto uma vez e o app cuida de lembrar.

## ⚙️ Como funciona

| Passo | O que acontece |
| :---: | --- |
| **1. Escaneie** | Aponte a câmera para o código de barras. O nome do produto aparece sozinho, com dados do Open Food Facts. |
| **2. Informe a validade** | Escolha o ano e o mês em dois toques e adicione. |
| **3. Veja tudo em uma lista** | Os produtos ficam em ordem de validade, com uma cor para cada situação. |
| **4. Receba o aviso** | Sete dias antes de vencer, às 9h, chega o lembrete. Responda na própria notificação: **Sim, já consumi** ou **Ainda tenho**. |

## ✨ Recursos

- 📷 **Leitura de código de barras** para cadastrar produtos em segundos
- 🧾 **Nota fiscal pelo QR Code** (NFC-e) para ver os produtos da compra
- 📋 **Lista Tenho e Acabou** para saber o que tem em casa e o que precisa comprar
- 🔔 **Lembretes com resposta rápida**, sem precisar abrir o app
- ⏰ **Lembrete de conferência** depois de 15 dias sem abrir o app
- 🔒 **Privacidade:** os dados ficam no celular, sem cadastro nem login

## 🌐 Sobre este site

Página única, feita em HTML, CSS e JavaScript puros, sem dependências. Tudo fica em um só arquivo: `index.html`.

- Vídeo de demonstração tocando dentro da própria página
- Seção "Como funciona" que troca as telas do app conforme a rolagem
- Menu fixo, menu próprio para celular e botão de voltar ao topo
- Layout adaptado para computador, tablet e celular
- Acessibilidade verificada com o [axe](https://github.com/dequelabs/axe-core), sem nenhum problema apontado: contraste, navegação por teclado, leitores de tela e respeito à preferência de reduzir animações

### Rodar no computador

Não precisa instalar nada. Basta abrir o arquivo `index.html` no navegador.

### Publicar

O site está publicado na [Vercel](https://vercel.com). Cada alteração enviada para este repositório é publicada automaticamente.
